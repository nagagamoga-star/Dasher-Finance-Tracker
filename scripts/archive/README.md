# Archived scripts

Legacy utilities kept for reference. Not used by BioDash v3.3+.

- `deep_clean.py` — one-off folder consolidation (pre-v3.2)
- `Project_auditor.py` — text tree audit generator
- `shift_logger.py` — retired simple CSV logger

Use `streamlit run app.py` and `src/logging/unified_logger.py` instead.
